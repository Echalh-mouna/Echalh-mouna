## 🚀 Featured Projects

<div align="center">

### 🤖 CERT AI Agent

**Agent d'automatisation pour équipe CERT : veille CTI multi-sources (NVD, CERT-FR, CISA KEV), génération de fiches d'alerte via LLM local (Ollama/Qwen2.5) et suivi de remédiation des vulnérabilités.**

`Python` `SQLite` `Ollama` `LLM` `Threat Intelligence` `CVE/CVSS` `Automation`

---

### 🎣 Phishing / Malicious URL Detection

**Système de détection précoce d'attaques pour PME marocaines : pipeline complet de la collecte de flux CTI (URLhaus) à un dashboard Streamlit avec alertes e-mail automatiques.**

`Python` `Scikit-learn` `Streamlit` `Machine Learning` `Cybersecurity`

---

### 🧩 Offline Reinforcement Learning

**Projet académique sur le RL offline avec réanalyse de trajectoires (Vine, MCTS, VAE, variante Critic-Guided), évalué sur les benchmarks D4RL (Hopper, HalfCheetah, Walker2d) via IQL.**

`Python` `Reinforcement Learning` `D4RL` `IQL`

---

### 🛡️ Hybrid IDS

**Système de détection d'intrusion hybride développé lors d'un stage, combinant approches basées sur les signatures et le machine learning.**

`Python` `Machine Learning` `Intrusion Detection` `MITRE ATT&CK`

</div>
